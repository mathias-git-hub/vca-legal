VCA Privacy Policy

Effective date: 2026-11-17

VCA (Viral Clip Agent) is a private tool operated by Mathias Løve for the operator's own use.

Google user data accessed

VCA accesses only events in the calendar it creates itself, "VCA posting", using the scope https://www.googleapis.com/auth/calendar.app.created. It does not access any other calendars, contacts, email or files.

Why

The data is used to schedule reminders for the operator's own social media posts and to read back changes the operator makes to those reminders.

Storage

Data is stored locally on the operator's own computer and server. OAuth tokens are protected at rest by the operating system's file permissions and are never shared.

Sharing and use

Google user data is not sold, not used for advertising, not shared with third parties, and not used to train AI models.

Retention and deletion

Data is deleted when the operator removes the "VCA posting" calendar or revokes access. Anyone can revoke access at https://myaccount.google.com/permissions.

Google API Services User Data Policy

VCA's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
